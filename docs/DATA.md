# Data

Where the programme days and video links come from, how they are stored, and how to add or correct them. The data in `seed/` is not covered by the code licence (`seed/README.md`).

## Sources and their status

| Source | Used for | Status |
|---|---|---|
| tvprogramme.net (volunteers transcribed printed TV guides) | almost all real programme days | `license_status = not_required`; credited on `/info`. The site is discontinued; a preservation copy lives outside the repository (`.data/archive/tvprogramme.net/`). |
| Own reconstruction from public sources | single curated days in `seed/` | own work |
| Own research (Wikipedia, broadcaster pages, dated recordings) | regular slots (`seed/regular-slots.json`) | each entry names its source |
| YouTube, Internet Archive, Dailymotion, Vimeo, Mediatheken | video links | links only; no rights claimed |

Sources that need a licence first (e.g. fernsehserien.de, wunschliste.de) are not scraped. `pnpm ingest sources` lists every source with its status; importers refuse sources that are not `granted` or `not_required`.

## Files

| File | Contents |
|---|---|
| `seed/YYYY-MM-DD.json` | one curated TV day (format below) |
| `seed/media-library.json` | curated video links for recurring shows, dated recordings and films; matched to broadcasts by title, channel and year |
| `seed/interstitials.json` | ads, idents, announcers, trailers, sign-offs (`channel` null = pool spot for any channel) |
| `seed/regular-slots.json` | researched regular slots (show, channel, weekdays, start, length, run period, source, confidence) |
| `seed/upload-review.json` | uploads the curation left out, with reasons; decided at `/admin/aussortiert` |
| `.data/archive/tvprogramme.net-seed/` (not in the repository) | the converted tvprogramme.net days and the assumed days, generated by `to_seed.py` |

### Day format

```jsonc
{
  "date": "1991-03-13", "tvDayStart": "06:00", "timezone": "Europe/Berlin",
  "completeness": "partial",              // optional: full | partial | series_only (assumed)
  "source": { "name": "…", "url": "…", "license": "…" },
  "channels": [{ "id": "ard", "name": "ARD", "displayNumber": 1, "isPrivate": false }],
  "broadcasts": [{ "channel": "ard", "start": "20:00", "end": "20:15",
                   "startMinOfTvDay": 1200, "endMinOfTvDay": 1215, "title": "Tagesschau", "description": null }],
  "media": [{ "matchTitle": "Tagesschau", "channel": "ard", "start": "20:00", "level": "exact",   // exact | same | sim
              "url": "https://www.youtube.com/watch?v=…", "note": "Tagesschau vom 13.03.1991", "alt": null, "durationS": 900 }],
  "adBreaks": [{ "channel": "rtl-plus", "url": "…", "note": "Werbung 1991" }]
}
```

Times are minutes from 00:00 of the TV day (06:00 → 06:00; after midnight above 1440). `level`: `exact` = this very broadcast, `same` = same show and year on that channel, `sim` = anything else similar.

## Adding or correcting a day

1. Visitors send programmes through `/mitmachen` (text or a photo of the guide); the moderation transcribes approved ones.
2. Write or fix the day as `seed/YYYY-MM-DD.json` in the format above (all times Europe/Berlin, TV day rules), with a `source`.
3. `pnpm db:setup` (development server stopped) re-imports everything; `pnpm test` also checks that no seed file contains an e-mail address.

## Assumed programme

For dates without a listing, `.data/archive/tvprogramme.net-data/to_seed.py` derives an assumed day (`completeness: series_only`):

- A slot seen at least 4 times on real days (same channel, start time and weekday pattern; holiday weeks ignored) is filled in only **between two sightings** in that same slot, at most 400 days apart, never on public holidays or between 20 December and 6 January.
- Researched slots from `seed/regular-slots.json` fill free times within their documented run; what the real days show comes first.
- A dated recording in the library puts that show into the day at its recorded or usual time.

Limits: an assumed day only knows regular programmes (series, news, talk shows, kids' blocks); one-off films and events are missing. The TV marks such days („Programm angenommen“), the calendar shows them dashed, and they are never chosen as start, best or random day.

## Rules for video links

- A matching title is not enough: check the uploader and what the video actually is.
- What aired on TV is linked, whatever its topic (conspiracy or UFO shows included); the uploader is checked only for whether the recording is genuine and from the right era.
- Erotic programmes that aired (Tutti Frutti, Playboy Late Night Show, Wa(h)re Liebe …), and announcements or trailers for them, are linked like any other programme (owner decision 11 Nov 2026; until then they waited in the review group `erotik-90er`). Material that never aired on these stations stays out.
- Exception: a right-wing channel that frames or comments the content and was active in the last five years → not linked; the find goes to `seed/upload-review.json` for the admin.
- Material that never aired (lectures, rallies, internet shows, propaganda) is never linked; neither are spam re-uploads or recordings from the wrong era.
- Verify technically: YouTube via oEmbed; Internet Archive only if the file itself plays (items can look public while every file is private).
- Notes name an uploader by channel name at most, never by e-mail address.
- Never download or re-host video; store URLs, ids and metadata only.

## Scripts outside the repository

The curation scripts (programme conversion `to_seed.py`, video searches against the YouTube Data API and the Internet Archive, uploader vetting, review groups) live on the owner's machine next to the preservation copy, not in this repository. They write only the seed files above. Their API keys (`YOUTUBE_API_KEY`, Internet Archive) are never needed by the web app or the server.
